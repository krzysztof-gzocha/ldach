# ldach.pl

Prosta, statyczna strona lądowania (jeden plik `index.html`, bez frameworka).

## Podgląd lokalnie

Wystarczy otworzyć `index.html` w przeglądarce.

## Deploy

Publikacja na GitHub Pages odbywa się automatycznie przy pushu na `master` (`.github/workflows/deploy.yaml`) — workflow wrzuca zawartość repo bezpośrednio jako artefakt Pages, bez etapu builda.
